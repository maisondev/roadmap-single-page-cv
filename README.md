# Currículo de Página Única

Um currículo de página única (single-page CV) com HTML semântico e otimizações de SEO.

## 🌐 Projeto

Este projeto é parte do desafio [Single Page CV](https://roadmap.sh/projects/single-page-cv) do Roadmap.sh.

## 📱 Site Publicado

Visualize o currículo em: https://maisondev.github.io/roadmap-single-page-cv/

## ✨ Características

- **HTML Semântico**: Uso de `<header>`, `<main>`, `<address>`, `<time>` e outras tags semânticas
- **Otimizações de SEO**: Meta tags (viewport, description, canonical) e Open Graph para compartilhamento em redes sociais
- **Favicon SVG**: Ícone personalizado com as iniciais "MG"
- **Responsivo**: Design adaptado para desktop, tablet e mobile
- **Links Estruturados**: `tel:` e `mailto:` para contato direto

## 📝 Conteúdo

- **Informações Pessoais**: Nome, profissão e dados de contato
- **Habilidades**: Competências técnicas (HTML, CSS, JavaScript, VueJS, Git, SQL)
- **Educação**: Formação acadêmica (IFAM, Gran Faculdade)
- **Experiência Profissional**: Histórico de trabalho (PRODAM, Prefeitura de Manaus)
- **Contato**: Links para site, e-mail e telefone
